# Boundary benchmark

Create a manually verified GeoJSON/JSON manifest for dealership operational
lots. Keep the reference polygon in a local or licensed dataset and record the
prediction generated by each provider/model on the same cases.

The evaluator in `src/main/services/boundary-benchmark.ts` reports:

- approximate polygon IoU;
- Boundary-F1 at a 2 m tolerance;
- reference-area coverage and the 90% coverage rate;
- area bias;
- confidence calibration bins.

Recommended stratification is by federal state, urban/rural context, lot area,
imagery vintage and source availability. Do not split randomly by nearby tiles:
hold out complete geographic areas to avoid spatial leakage.

Example sample shape:

```ts
{
  id: "dealer-berlin-001",
  reference: { type: "Polygon", coordinates: [[[13.1, 52.4], ...]] },
  predicted: { type: "Polygon", coordinates: [[[13.1, 52.4], ...]] },
  predictedSource: "osm",
  predictedConfidence: 0.81
}
```
